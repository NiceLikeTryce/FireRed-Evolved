FIRERED EVOLV3D / NINTENDO 3DS

Play from your HOME Menu.

For an Old or New 3DS/2DS with Luma3DS and FBI. Use your own supported FireRed ROM to build the game once.

1. Build your game

Choose your clean FireRed v1.0 or v1.1 ROM in the patcher and select the Nintendo 3DS edition.

Open the 3DS builder

2. Install the HOME launcher

On the 3DS, open FBI → Remote Install → Scan QR Code. Scan this code to install the FireRed Evolv3D icon.

Loading the current installation tools…

Download the launcher CIA

The launcher starts the game you build. The game is not included in the launcher.

3. Send your game wirelessly

Download wireless setup for Windows

  1. Extract the downloaded ZIP and open FireRed-Evolv3D-Wireless.exe.
  2. Choose the generated .3dsx file.
  3. Keep the computer and 3DS on the same home Wi-Fi.
  4. Scan the companion’s game QR code in FBI. When FBI finishes, open the FireRed Evolv3D HOME icon.

Mac/Linux Python source and instructions are included in the ZIP. You can also copy the game to /3ds/FireRed-Evolv3D/FireRed-Evolv3D.3dsx on the SD card.

4. Update from the game

Open Options → General → Tools → Check for updates. The game saves before opening the launcher. Review the release notes, then confirm the update. Install launcher 1.1.0 using the QR above to see the notes.

The updater verifies its patch data, keeps the previous game and a save snapshot, then replaces the game. Recovery can restore the previous version while keeping your saved progress.

Hold SELECT when opening the HOME icon to open its maintenance menu directly.
